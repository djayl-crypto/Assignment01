# Assignment01 — 나에게 맞는 도시생활 유형 찾기

스마트도시데이터분석 수업의 첫 번째 과제입니다. Python으로 도시환경에 대한 선호를 묻고, 응답을 점수화하여 도시생활 유형을 알려주는 앱을 만들 예정입니다.

## 과제 목표

- 함수, 조건문, 반복문을 활용하여 앱을 구현합니다.
- GitHub에 코드를 관리하고 푸시합니다.
- 완성한 앱을 Cloudflare로 배포합니다.

## 앱 소개

공원과 산책로, 대중교통, 상업시설, 주거환경, 문화시설에 관한 질문에 답하면 선호에 맞는 도시생활 유형과 설명을 제공합니다.

예정된 결과 유형:

- 도심활동형
- 녹지친화형
- 대중교통형
- 조용한주거형
- 문화생활형

## Python 학습 내용 활용 계획

| 학습 내용 | 앱에서의 활용 |
| --- | --- |
| 변수와 기본 자료형 | 현재 질문 번호, 사용자 응답, 점수 저장 |
| 리스트 | 질문 목록과 응답 기록 저장 |
| 딕셔너리 | 질문 정보, 유형별 점수와 결과 설명 저장 |
| 조건문 (`if`, `elif`, `else`) | 응답 검증, 응답에 따른 점수 계산, 결과 판정 |
| 반복문 (`for`, `while`) | 질문과 점수 순회, 필요한 입력 재시도 처리 |
| 함수 (`def`) | 입력 검증, 점수 계산, 결과 판정을 역할별로 분리 |

수업에서 배운 문법의 사용 목적이 드러나도록 읽기 쉬운 코드와 한국어 주석을 작성할 예정입니다.

## 구현 예정 기능

- 도시생활 선호 질문과 응답 입력
- 올바르지 않은 입력에 대한 안내
- 유형별 점수 계산
- 최고 점수 유형 판정 및 동점 처리
- 결과 설명과 유형별 점수 표시
- 테스트 다시 시작
