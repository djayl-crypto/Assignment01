# CITY:FIT — 나에게 맞는 도시생활 유형 찾기

**10개의 질문으로 발견하는 나만의 도시생활 취향.**

**[CITY:FIT 앱 바로가기](https://assignment01.djl-urban.workers.dev)**

CITY:FIT은 공원, 대중교통, 상업시설, 조용한 주거환경, 문화시설에 관한 선호를 묻고, 응답에 어울리는 도시생활 유형과 설명을 보여주는 **Python 기반 웹앱**입니다. 스마트도시데이터분석 수업의 첫 번째 과제로, 함수·조건문·반복문을 활용하여 구현했습니다.

## 사용 흐름

1. 시작 화면에서 **나의 도시 취향 찾기**를 누릅니다.
2. 10개 문항에 5단계 척도로 답합니다. 이전 버튼으로 답변을 수정할 수 있습니다.
3. 결과 화면에서 나의 유형, 유형별 점수, 생활환경 설명과 동네 탐색 팁을 확인합니다.
4. **내 답변 돌아보기**로 응답을 수정하거나 **다시 테스트하기**로 새로 시작합니다.

아이보리 배경과 초록색을 중심으로 디자인했으며, 데스크톱과 모바일 화면에 대응합니다. 회원가입 없이 이용하며, 응답을 파일이나 데이터베이스에 저장하지 않습니다. 새로고침하면 응답이 초기화됩니다.

## 다섯 가지 도시생활 유형

| 유형 | 중요하게 생각하는 일상 |
| --- | --- |
| 녹지친화형 | 가까운 공원, 나무 그늘, 산책로 |
| 대중교통형 | 편리한 대중교통, 환승, 보행 연결 |
| 도심활동형 | 카페와 식당, 생활 편의, 활기 있는 거리 |
| 조용한주거형 | 차분한 골목과 편안한 휴식 |
| 문화생활형 | 전시와 공연, 도서관, 동네 책방 |

최고 점수가 같은 유형이 여러 개라면 **다채로운 도시생활자**로 표시하고 동점 유형을 모두 안내합니다. 모든 유형이 0점이면 **나의 도시 취향 탐색 중**으로 표시합니다.

## Python으로 구현한 핵심 로직

질문·유형 데이터와 계산 로직은 [quiz.py](quiz.py)에 모았습니다. HTML과 CSS는 화면을 구성하고, JavaScript는 화면 전환과 응답 전달을 담당합니다. **입력 검증, 점수 계산, 최종 유형 판정은 Python 서버에서 실행합니다.**

| 수업에서 배운 내용 | 코드에서의 활용 |
| --- | --- |
| 변수와 기본 자료형 | 사용자 응답, 문항 번호, 점수와 판정 상태 표현 |
| 리스트 | `QUESTIONS`, 사용자 응답, 최고 점수 유형 목록 |
| 딕셔너리 | `CITY_TYPES`, 질문 정보, 유형별 점수표 |
| 조건문 `if / elif / else` | 응답 검증, 응답별 점수 변환, 동점과 전체 0점 처리 |
| 반복문 `for` | 질문과 응답 순회, 유형별 점수 누적, 최고 점수 탐색 |
| 함수 `def` | `check_answer()`, `answer_to_points()`, `find_best_types()`, `calculate_result()` |

### 점수 계산

각 유형에 두 문항씩 배정하고, 아래 기준으로 응답을 점수로 바꿉니다.

| 응답 | 입력값 | 점수 |
| --- | ---: | ---: |
| 매우 그렇다 | 5 | 4 |
| 그렇다 | 4 | 3 |
| 보통이다 | 3 | 2 |
| 그렇지 않다 | 2 | 1 |
| 전혀 그렇지 않다 | 1 | 0 |

유형별 최고 점수는 **8점**입니다. 결과 화면의 백분율은 각 유형의 점수를 8점으로 나눈 값을 정수로 반올림한 것입니다. 유형별 점수는 서로 독립적이며, 백분율의 합계가 100%일 필요는 없습니다.

서버는 응답 개수와 값의 범위를 검증합니다. 점수표는 요청마다 새로 만들어 다른 사용자의 응답이나 이전 테스트 점수가 섞이지 않도록 했습니다.

## 프로젝트 구성

| 파일 | 역할 |
| --- | --- |
| [quiz.py](quiz.py) | 질문과 유형 데이터, 입력 검증, 점수 계산, 결과 판정 |
| [app.py](app.py) | 로컬 HTTP 서버, 정적 파일 제공, API 연결 |
| [worker.py](worker.py) | Cloudflare에서 실행되는 Python API 진입점 |
| [wrangler.jsonc](wrangler.jsonc) | Python Worker와 정적 화면 배포 설정 |
| [static/index.html](static/index.html) | 시작·질문·결과 화면 구조 |
| [static/style.css](static/style.css) | 색상, 배치, 모바일 대응 스타일 |
| [static/script.js](static/script.js) | 화면 전환, 답변 선택과 수정, Python API 호출 |
| [static/city.svg](static/city.svg) | 도시 일러스트 |
| [test_quiz.py](test_quiz.py) | 핵심 로직과 HTTP API 검증 |

서버는 `GET /api/quiz`로 질문과 유형 정보를 제공하고, `POST /api/result`로 전달된 응답을 계산해 결과를 반환합니다.
